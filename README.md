Butcheritems es un plugin para servidores minecraft bedrock que usan software nukkit.
Elimina entidades y bloques flotantes para disminuir el lag.

Facil manejo y uso.
Mensajes altamente customizable.

El codigo original no es de mi pertenencia.

Si encuentras algún error por favor informarlo.

el plugin es compatible con:
- NPC Slapper
- KotlinLib
- PlaceholderApi

Puedes descargar la ultima version desde:

https://cloudburstmc.org/resources/butcher-items.1121/
